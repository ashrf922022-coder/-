# AWRIDI AI v3.1 — Android

هذه نسخة محسّنة من v3، مخصصة للبحث والتحليل والاختبار الورقي، وليست منصة تنفيذ أوامر حقيقية.

## التحسينات في v3.1
- إصلاح حساب SMA في شاشة التحليل.
- تحسين حساب RSI وATR عندما تكون نافذة البيانات أقصر.
- عرض نتائج فحص السوق داخل الشاشة بدل نافذة Toast صغيرة.
- معالجة أفضل للرموز الفارغة.
- الإبقاء على Backtesting وStrategy Studio وDesign Studio.
- إصدار التطبيق 3.1.

## طريقة البناء
يوجد GitHub Actions في `.github/workflows/build-apk.yml`. بعد رفع ملفات المشروع إلى مستودع GitHub وتشغيل Workflow، ينتج ملف APK تجريبي قابل للتثبيت على الهاتف.

## مهم
النتائج التاريخية ليست ضمانًا للنتائج المستقبلية، والنسخة الحالية لا ترسل أوامر شراء أو بيع حقيقية.
