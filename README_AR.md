# AWRIDI AI Gold v3.1 — مساعد تداول وتحليل الذهب (XAU/USD)

تحويل تطبيق AWRIDI AI إلى مساعد تداول متخصص حصريًا في الذهب (XAU/USD)، يركز على التحليل الفني متعدد المؤشرات والأطر الزمنية، إدارة المخاطر، التداول التجريبي الورقي (Paper Trading)، الاختبار التاريخي (Backtesting)، والتعليم التفاعلي.

---

## 🌟 الميزات الرئيسية

1. **التركيز على الذهب (XAU/USD)**: الذهب هو الأصل المالي الرئيسي والوحيد في النظام.
2. **اتصال آمن بـ Twelve Data**: سحب البيانات الحية عبر API وحفظ المفتاح بشكل آمن في إعدادات التطبيق دون تخزينه داخل الكود أو GitHub.
3. **المؤشرات التقنية**:
   - RSI (14)
   - MACD (12, 26, 9)
   - المتوسطات المتحركة EMA 20, EMA 50, EMA 200
   - ATR (14) للتقلب
   - نقاط الدعم والمقاومة Pivot Points
   - الاتجاه العام والزخم
4. **تحليل متعدد الأطر (Multi-Timeframe)**: جلب البيانات للأطر 5m, 15m, 1h, 4h وتقييم الاتجاه العام للإطار الأكبر.
5. **محرك القرار المشروط**:
   - `BUY SETUP` 🟢
   - `SELL SETUP` 🔴
   - `WAIT` ⏳
   - `NO TRADE` 🚫 (عند التقلب الشديد أو تضارب المؤشرات لحماية رأس المال)
6. **شرح عربي تفصيلي**: توضيح أسباب كل قرار والمؤشرات المؤيدة والمخالفة ونسبة الثقة.
7. **إدارة المخاطر**:
   - حساب سعر الدخول (Entry)، وقف الخسارة (SL)، الأهداف (TP1 / TP2).
   - نسبة المخاطرة/العائد (Risk/Reward).
   - حساب حجم الصفقة المقترح (Lot Size) بناءً على نسبة المخاطرة المحددة (مثال: 1% من رأس المال).
8. **التداول التجريبي (Paper Trading)**:
   - فتح صفقات افتراضية متابعة نتائجها وقيد الأرباح/الخسائر بدون أي أموال حقيقية.
   - سجل تاريخي كامل بالصفقات وتفاصيلها.
9. **محاكي الاختبار التاريخي (Backtesting)**:
   - تشغيل اختبار على البيانات التاريخية للذهب وإظهار: عدد الصفقات، Win Rate %، Profit Factor، Max Drawdown %، أطول سلسلة خسائر، ورأس المال النهائي.
10. **تكامل Telegram و TradingView**:
    - إرسال الإشارات تلقائيًا إلى Telegram Bot وChat ID المحدد.
    - دعم صيغة Webhook JSON لربط تنبيهات TradingView.
11. **المساعد التعليمي العربي**:
    - شرح شامل للمؤشرات والمفاهيم التداولية للمبتدئين مع التأكيد على عدم وجود أرباح مضمونة.

## 🚀 طريقة البناء والتشغيل

1. **البناء المحلي عبر Gradle**:
   ```bash
   gradle assembleDebug
   ```
   سيتم إنتاج ملف APK في المسار:
   `app/build/outputs/apk/debug/app-debug.apk`

2. **التشغيل والإعداد**:
   - افتح التطبيق على الهاتف أو المحاكي.
   - انتقل إلى شاشة **الإعدادات**.
   - أدخل مفتاح **Twelve Data API Key**.
   - (اختياري) أدخل **Telegram Bot Token** و **Chat ID** لاستقبال التنبيهات.
   - قم بضبط رأس المال التجريبي ونسبة المخاطرة.
   - اضغط **حفظ الإعدادات**.
   - عد للشاشة **الرئيسية** واضغط **بدء تحليل XAU/USD**.
